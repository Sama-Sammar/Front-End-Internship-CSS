Task 1: Circle

Question:
Create a circular div with a diameter of 100px.

Center the text inside the circle both vertically and horizontally.

Add a gradient background behind the circle using a pseudo-element (::before).

Task 2: Parent Flex Container

Question:
Create a flex container with six divs inside.

The container should have a fixed width of 600px and height of 300px.

Arrange the divs in rows and columns with space between them using Flexbox.

Each div should have a width of 180px, height of 50px, and centered text.

Task 3: Parent2 Grid Layout

Question:
Create a 3x2 grid container with six divs inside.

Place each div in a specific cell using grid-row and grid-column.

Adjust the height and vertical alignment of some items differently.

Make sure the container has some padding and gaps between items.

Task 4: Parent3 Grid Layout

Question:
Create a grid container with two columns and two rows.

Place three divs inside, making one div span multiple rows.

Use justify-self and align-self to position the divs differently inside the grid.

Set custom width and height for each grid item.

Task 5: Page Layout (Header, Main, Footer)

Question:
Create a page layout with a header, main area, and footer.

Use Flexbox to arrange items horizontally inside the header and footer.

The main area should have a content section and a sidebar in a 3:1 ratio.

Style the sections with different background colors and center the text.
