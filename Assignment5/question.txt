</div>
Create the layout exactly as shown in the example.
Make sure that any change in the padding or border of the parent element (div) is automatically applied 
to the child element (p) without directly editing the child element.

In the second shape, use the Cairo font with a weight of 700.
In the third shape, use the Jomhuria font with a weight of 400.

Make sure each font is imported correctly from Google Fonts.
